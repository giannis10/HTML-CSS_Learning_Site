💡 Επικεφαλίδες (Headings

έως

)

Στην HTML υπάρχουν έξι επίπεδα επικεφαλίδων. Το <h1> είναι η σημαντικότερη επικεφαλίδα (μεγαλύτερο μέγεθος), ενώ το <h6> είναι το χαμηλότερο επίπεδο.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Επικεφαλίδες</title>
	</head>
	<body>
		<h1>Αυτή είναι μια Κύρια Επικεφαλίδα (Επίπεδο 1)</h1>
		<h2>Αυτή είναι μια Επικεφαλίδα Επιπέδου 2</h2>
		<h3>Αυτή είναι μια Επικεφαλίδα Επιπέδου 3</h3>
		<h4>Αυτή είναι μια Επικεφαλίδα Επιπέδου 4</h4>
		<h5>Αυτή είναι μια Επικεφαλίδα Επιπέδου 5</h5>
		<h6>Αυτή είναι μια Επικεφαλίδα Επιπέδου 6</h6>
	</body>
</html>
