💡 Τεχνική CSS Sprites για Κουμπιά Rollover

Συνδυάστε όλες τις καταστάσεις ενός κουμπιού (κανονικό, hover, active) σε μία ενιαία εικόνα και μετατοπίστε απλώς τη θέση του φόντου (background-position) για ακαριαία απόκριση χωρίς καθυστέρηση φόρτωσης.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Εφέ Rollover και CSS Sprites</title>
		<style type="text/css">
			a.button {
				height: 36px;
				background-image: url("images/button-sprite.jpg");
				text-indent: -9999px;
				display: inline-block;}
			a#add-to-basket {
				width: 174px;
				background-position: 0px 0px;}
			a#framing-options {
				width: 210px;
				background-position: -175px 0px;}
			a#add-to-basket:hover {
				background-position: 0px -40px;}
			a#framing-options:hover {
				background-position: -175px -40px;}
			a#add-to-basket:active {
				background-position: 0px -80px;}
			a#framing-options:active {
				background-position: -175px -80px;}
		</style>
	</head>
	<body>
		<a class="button" id="add-to-basket">Προσθήκη στο καλάθι</a>
		<a class="button" id="framing-options">Επιλογές κορνίζας</a>
	</body>
</html>
