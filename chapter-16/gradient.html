💡 Διαβαθμίσεις Χρώματος CSS3 (Gradients)

Δημιουργήστε ομαλές μεταβάσεις χρωμάτων χωρίς εικόνες χρησιμοποιώντας linear-gradient(χρώμα1, χρώμα2).

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>CSS3: Διαβαθμίσεις Χρώματος (Gradients)</title>
		<style type="text/css">
			#gradient {
				/* fallback color */
				background-color: #66cccc; 
				/* fallback image */
				background-image: url("images/fallback-image.png"); 
				/* Firefox 3.6+ */
				background-image: -moz-linear-gradient(#336666, #66cccc);
				/* Safari 4+, Chrome 1+ */
				background-image: -webkit-gradient(linear, 0% 0%, 0% 100%, from(#66cccc), to(#336666));
				/* Safari 5.1+, Chrome 10+ */
				background-image: -webkit-linear-gradient(#336666, #66cccc); 
				/* Opera 11.10+ */
				background-image: -o-linear-gradient(#336666, #66cccc);
   				height: 150px;
				width: 300px;}
		</style>
	</head>
	<body>
		<div id="gradient">
		</div>
	</body>
</html>
