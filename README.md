## ✨ Κύρια Χαρακτηριστικά

- **🌙 Premium Dark Theme UI:** Μοντέρνα αισθητική υψηλής ποιότητας (glassmorphism, curated dark palette, responsive typography) χωρίς περιττό οπτικό θόρυβο.
- **📚 17 Θεματικά Κεφάλαια:** Καλύπτει τα πάντα από τη βασική δομή HTML, μορφοποίηση κειμένου, πίνακες και φόρμες μέχρι προχωρημένο CSS (Flexbox, Grid, Floats, Positioning, Animations).
- **💡 Διαδραστικά Code Boxes:** Κάθε παράδειγμα συνοδεύεται από:
  - Οπτική ζωντανή προβολή.
  - Αναλυτικό οδηγό & επεξήγηση λειτουργίας στα ελληνικά.
  - Πλαίσιο πηγαίου κώδικα με αρίθμηση γραμμών και κουμπί **«Αντιγραφή Κώδικα»**.
- **🎮 Quiz Hub (Στυλ Duolingo):**
  - **20 Θεματικά Quiz x 20 Ερωτήσεις = 400 Μοναδικές Ερωτήσεις** με 4 επιλογές και άμεση εκπαιδευτική επεξήγηση.
  - Ζωντανό σύστημα σερί (**Streak 🔥**) και πόντων (**XP**).
  - Αυθεντικά ηχητικά εφέ επιβράβευσης μέσω Web Audio API (χωρίς εξωτερικά αρχεία).
  - Αποθήκευση σκορ και επιτευγμάτων στο πρόγραμμα περιήγησης (`localStorage`).
  - Πλήκτρα συντομεύσεων (1-4 για επιλογή απάντησης, Space/Enter για επόμενη ερώτηση).
- **⚡ 100% Client-Side:** Δεν απαιτείται backend ή βάση δεδομένων — τρέχει απευθείας σε οποιονδήποτε σύγχρονο περιηγητή (Chrome, Edge, Firefox, Safari).

## 🛠️ Τοπική Εκτέλεση (Local Development)

Μπορείτε να εκτελέσετε το project τοπικά στον υπολογιστή σας:

### Επιλογή 1: Απευθείας στον Browser
Απλώς κάντε διπλό κλικ στο αρχείο `index.html` ή σύρετέ το μέσα σε οποιοδήποτε παράθυρο browser.

### Επιλογή 2: Μέσω Τοπικού HTTP Server (Προτεινόμενο)
Αν έχετε εγκατεστημένη την Python:
```bash
# Μετάβαση στον φάκελο του project
cd HTML-CSS_Learning_Site

# Εκκίνηση τοπικού server στη θύρα 8090
python -m http.server 8090
```
Στη συνέχεια ανοίξτε τον browser στο:
```
http://localhost:8090
```
