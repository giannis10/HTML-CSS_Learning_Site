Για περίοδο ενός έτους από τον Νοέμβριο του 2010, το Μουσείο Σύγχρονης Τέχνης Marugame Genichiro-Inokuma (MIMOCA) θα φιλοξενήσει έναν κύκλο τεσσάρων εκθέσεων του Hiroshi Sugimoto.

Κάθε μία θα παρουσιάζει έργα του καλλιτέχνη θεματικά πλαισιωμένα κάτω από τις ενότητες «Επιστήμη», «Αρχιτεκτονική», «Ιστορία» και «Θρησκεία», ώστε να παρουσιάσει ένα ολοκληρωμένο πανόραμα του έργου του.

Ώρες λειτουργίας: 10:00 - 18:00 (Τελευταία είσοδος στις 17:30)

Οδηγός & Επεξήγηση

💡 Το Γνώρισμα Class (class="όνομα_κλάσης")

Το γνώρισμα class χρησιμοποιείται για να ομαδοποιήσει πολλαπλά διαφορετικά στοιχεία υπό το ίδιο όνομα, επιτρέποντας κοινή μορφοποίηση στο CSS (με .class).

💻 Πηγαίος Κώδικας Παραδείγματος

<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Το Γνώρισμα Class (Class Attribute)</title>
		<style type="text/css">
			.important {
				text-transform: uppercase;}
			.admittance {
				color: #FF6666;}
		</style>
	</head>
	<body>
		<p class="important">Για περίοδο ενός έτους από τον Νοέμβριο του 2010, το Μουσείο Σύγχρονης Τέχνης Marugame Genichiro-Inokuma (MIMOCA) θα φιλοξενήσει έναν κύκλο τεσσάρων εκθέσεων του Hiroshi Sugimoto.</p>
