💡 Πεδίο Κωδικού Πρόσβασης ()

Με το <input type="password">, οι χαρακτήρες που πληκτρολογεί ο χρήστης αποκρύπτονται αυτόματα με τελείες ή αστερίσκους για ασφάλεια.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Πεδίο Κωδικού Πρόσβασης (Password Input)</title>
	</head>
	<body>
		<form action="http://www.example.com/login.php">
			<p>Όνομα χρήστη:
				<input type="text" name="username" size="15" maxlength="30" />
			</p>
			<p>Κωδικός πρόσβασης:
				<input type="password" name="password" size="15" maxlength="30" />
			</p>
		</form>
	</body>
</html>
