💡 Πεδίο Αναζήτησης HTML5 ()

Εξειδικευμένο πεδίο αναζήτησης που συχνά περιλαμβάνει κουμπί άμεσου καθαρισμού (clear) και προσαρμόζεται στο UI του λειτουργικού συστήματος.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Πεδίο Αναζήτησης HTML5</title>
	</head>
	<body>
		<form action="http://www.example.org/search.php">
			<p>Αναζήτηση:</p>
			<input type="search" name="search" />
			<input type="submit" value="Αναζήτηση" />
		</form>
	</body>
</html>
⬅ Επιστροφή στον Πίνακα Περιεχομένων
