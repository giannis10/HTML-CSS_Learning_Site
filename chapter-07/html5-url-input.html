💡 Πεδίο Διεύθυνσης URL HTML5 ()

Το type="url" ελέγχει αυτόματα αν ο χρήστης εισήγαγε σωστή διεύθυνση ιστοτόπου (ξεκινώντας με πρωτόκολλο όπως http://).

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Πεδίο URL HTML5</title>
	</head>
	<body>
		<form action="http://www.example.org/profile.php"> 
			<p>Παρακαλούμε εισαγάγετε τη διεύθυνση του ιστοτόπου σας:</p>
			<input type="url" name="website" />
			<input type="submit" value="Υποβολή" />
		</form>
	</body>
</html>
