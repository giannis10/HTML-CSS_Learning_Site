💡 Πεδίο Μεταφόρτωσης Αρχείου ()

Επιτρέπει στον χρήστη να επιλέξει αρχείο από τον υπολογιστή του για μεταφόρτωση. Για αποστολή αρχείων, η φόρμα πρέπει να έχει method="post".

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Πεδίο Εισαγωγής Αρχείου (File Input)</title>
	</head>
	<body>
		<form action="http://www.example.com/upload.php" method="post">
			<p>Μεταφορτώστε το τραγούδι σας σε μορφή MP3:</p>
			<input type="file" name="user-song" /><br />
			<input type="submit" value="Μεταφόρτωση" />
		</form>
	</body>
</html>
