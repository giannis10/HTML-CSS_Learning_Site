Οδηγός & Επεξήγηση

💡 Πώς Λειτουργεί η Διαδοχή (Cascade) στο CSS

Όταν πολλοί κανόνες εφαρμόζονται στο ίδιο στοιχείο, η προτεραιότητα καθορίζεται από τη σειρά δήλωσης, την ειδικότητα του επιλογέα και τη δήλωση !important.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Πώς Λειτουργεί η Διαδοχή (Cascade) στο CSS</title>
		<style type="text/css">
			* {
				font-family: Arial, Verdana, sans-serif;}
			h1 {
				font-family: "Courier New", Courier, monospace;}
			i {
				color: green;}
			i {
				color: red;}
			b {
				color: pink;}
			p b {
				color: blue !important;}
			p b {
				color: violet;}
			p#intro {
				font-size: 100%;}
			p {
				font-size: 75%;}
		</style>
	</head>
	<body>
		<h1>Πατάτες</h1>
		<p id="intro">Υπάρχουν <i>δεκάδες</i> διαφορετικές ποικιλίες <b>πατάτας</b>.</p>
		<p>Συνήθως περιγράφονται ως πρώιμες, μεσοπρώιμες και όψιμες πατάτες κύριας σοδειάς.</p>
	</body>
</html>
