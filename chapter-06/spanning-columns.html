💡 Συγχώνευση Στηλών (colspan)

Χρησιμοποιήστε το γνώρισμα colspan="2" σε ένα κελί <td> ή <th> ώστε να εκταθεί σε περισσότερες από μία στήλες.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Συγχώνευση Στηλών (Spanning Columns - Colspan)</title>
		<style type="text/css">
			table {
				border: none;}
			th, td {
				border: none;
				background-color: #dddddd;
				padding: 5px;
				width: 100px;}
		</style>
	</head>
	<body>
		<table>
			<tr>
				<th></th>
				<th>9:00 πμ</th>
				<th>10:00 πμ</th>
				<th>11:00 πμ</th>
				<th>12:00 μμ</th>
			</tr>
			<tr>
				<th>Δευτέρα</th>
				<td colspan="2">Γεωγραφία</td>
				<td>Μαθηματικά</td>
				<td>Καλλιτεχνικά</td>
			</tr>
			<tr>
				<th>Τρίτη</th>
				<td colspan="3">Γυμναστική</td>
				<td>Οικιακή Οικονομία</td>
			</tr>
		</table>
	</body>
</html>
