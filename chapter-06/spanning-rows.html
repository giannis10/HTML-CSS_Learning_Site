💡 Συγχώνευση Γραμμών (rowspan)

Χρησιμοποιήστε το γνώρισμα rowspan="2" ώστε ένα κελί να εκταθεί κατακόρυφα σε περισσότερες από μία γραμμές.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Συγχώνευση Γραμμών (Spanning Rows - Rowspan)</title>
		<style type="text/css">
			table {
				border: none;}
			th, td {
				border: none;
				background-color: #dddddd;
				padding: 5px;
				width: 100px;}
		</style>
	</head>
	<body>
		<table>
			<tr>
				<th></th>
				<th>ABC</th>
				<th>BBC</th>
				<th>CNN</th>
			</tr>
			<tr>
				<th>6:00 μμ - 7:00 μμ</th>
				<td rowspan="2">Ταινία</td>
				<td>Κωμωδία</td>
				<td>Ειδήσεις</td>
			</tr>
			<tr>
				<th>7:00 μμ - 8:00 μμ</th>
				<td>Αθλητικά</td>
				<td>Επικαιρότητα</td>
			</tr>
		</table>
	</body>
</html>
