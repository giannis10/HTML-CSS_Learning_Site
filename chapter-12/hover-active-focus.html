💡 Ψευδοκλάσεις Αλληλεπίδρασης (:hover, :active, :focus)

Αλλάξτε την εμφάνιση στοιχείων κατά την αιώρηση του ποντικιού (:hover), το πάτημα του κουμπιού (:active) ή την εστίαση σε πεδίο (:focus).

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Καταστάσεις :hover, :active, :focus</title>
		<style type="text/css">
			input {
				padding: 6px 12px 6px 12px;
				border: 1px solid #665544;
				color: #ffffff;}
			input.submit:hover {
				background-color: #665544;}
			input.submit:active {
				background-color: chocolate;}
			input.text {
				color: #cccccc;}
			input.text:focus {
				color:#665544;}
		</style>
	</head>
	<body>
		<form>
			<input type="text" class="text" value="Εισαγάγετε διεύθυνση email..." placeholder="Εισαγάγετε email..." />
			<input type="submit" class="submit" />
		</form>
	</body>
</html>
