💡 Κατακόρυφη Στοίχιση Inline Στοιχείων (vertical-align)

Στοιχίστε εικόνες ή κείμενο σε σχέση με τη γραμμή βάσης χρησιμοποιώντας baseline, text-top ή text-bottom.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Κατακόρυφη Στοίχιση (Vertical Align)</title>
		<style type="text/css">
			#six-months {
				vertical-align: text-top;}
			#one-year {
				vertical-align: baseline;}
			#two-years {
				vertical-align: text-bottom;}
		</style>
	</head>
	<body>
		<h1>Στάδια Ζωής του Briard</h1>
		<p><img src="images/six-months.gif" width="50" height="50" alt="Έξι μηνών" id="six-months" /> Έξι μηνών</p>
		<p><img src="images/one-year.gif" width="50" height="50" alt="Ενός έτους" id="one-year" /> Ενός έτους</p>
		<p><img src="images/two-years.gif" width="50" height="50" alt="Δύο ετών" id="two-years" /> Δύο ετών</p>
	</body>
</html>
