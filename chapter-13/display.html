💡 Τύπος Εμφάνισης Στοιχείου (display)

Μετατρέψτε στοιχεία λίστας σε οριζόντια με display: inline; ή αποκρύψτε στοιχεία εντελώς από τη ροή της σελίδας με display: none;.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Τύπος Εμφάνισης (Display)</title>
		<style type="text/css">
			body {
				font-family: Arial, Verdana, sans-serif;
				color: #111111;}
			li {
				display: inline; 
				margin-right: 10px;}
			li.coming-soon {
				display: none;}
		</style>
	</head>
	<body>
		<ul>
			<li>Αρχική</li>
			<li>Προϊόντα</li>
			<li class="coming-soon">Υπηρεσίες</li>
			<li>Σχετικά</li>
			<li>Επικοινωνία</li>
		</ul>
	</body>
</html>
