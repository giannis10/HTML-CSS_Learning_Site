💡 Ορατότητα Στοιχείου (visibility)

Η ιδιότητα visibility: hidden; αποκρύπτει οπτικά ένα στοιχείο, αλλά διατηρεί άδειο τον χώρο που καταλαμβάνει στη σελίδα (σε αντίθεση με το display: none).

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Ορατότητα (Visibility)</title>
		<style type="text/css">
			body {
				font-family: Arial, Verdana, sans-serif;
				color: #111111;}
			li {
				display: inline; 
				margin-right: 10px;}
			li.coming-soon {
				visibility: hidden;}
		</style>
	</head>
	<body>
		<ul>
			<li>Αρχική</li>
			<li>Προϊόντα</li>
			<li class="coming-soon">Υπηρεσίες</li>
			<li>Σχετικά</li>
			<li>Επικοινωνία</li>
		</ul>
	</body>
</html>
