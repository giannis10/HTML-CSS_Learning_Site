Φοιτητικός Οδηγός & Εργαστήριο

Γρήγορος Οδηγός Αναφοράς (Cheat Sheet)

Συνοπτικοί πίνακες με τις πιο συχνά χρησιμοποιούμενες ετικέτες HTML5 και ιδιότητες CSS3 για εργαστηριακές ασκήσεις και εξετάσεις.

Ετικέτα HTML5 Περιγραφή & Χρήση Παράδειγμα Σύνταξης
<!DOCTYPE html> Δήλωση τύπου εγγράφου HTML5 στην 1η γραμμή. <!DOCTYPE html>
<meta charset="utf-8"> Κωδικοποίηση χαρακτήρων για υποστήριξη ελληνικών. <meta charset="utf-8">
<h1> έως <h6> Επικεφαλίδες κειμένου κατά ιεραρχία σημασίας. <h1>Κύριος Τίτλος</h1>
<p> Παράγραφος κειμένου. <p>Κείμενο άρθρου...</p>
<a href="..."> Υπερσύνδεσμος σε άλλη σελίδα ή άγκυρα. <a href="page.html">Σύνδεσμος</a>
<img src="..." alt="..."> Εικόνα με υποχρεωτικό εναλλακτικό κείμενο προσβασιμότητας. <img src="pic.jpg" alt="Περιγραφή">
<ul> & <ol> Μη αριθμημένη (κουκκίδες) και αριθμημένη λίστα στοιχείων <li>. <ul><li>Στοιχείο 1</li></ul>
<table>, <tr>, <td>, <th> Δόμηση πινάκων δεδομένων με γραμμές και κελιά. <table><tr><th>Τίτλος</th></tr></table>
<form action="..." method="..."> Διαδραστική φόρμα υποβολής στοιχείων. <input type="text" name="user">
<header>, <nav>, <main>, <footer> Σημασιολογικά στοιχεία διάταξης HTML5 για SEO και καθαρό κώδικα. <header><nav>...</nav></header>
Ιδιότητα CSS3 Λειτουργία Ενδεικτική Τιμή
color & background-color Χρώμα γραμμάτων και χρώμα φόντου στοιχείου. color: #38bdf8; background: #0f172a;
font-family & font-size Γραμματοσειρά και μέγεθος κειμένου. font-family: Arial, sans-serif; font-size: 16px;
margin Εξωτερικό περιθώριο γύρω από το στοιχείο (κενό). margin: 20px auto;
padding Εσωτερική απόσταση ανάμεσα στο περιεχόμενο και το περίγραμμα. padding: 12px 18px;
border & border-radius Περίγραμμα και στρογγυλεμένες γωνίες. border: 1px solid #334155; border-radius: 8px;
display Τρόπος εμφάνισης (block, inline, flex, grid, none). display: flex; justify-content: center;
position Μέθοδος τοποθέτησης (static, relative, absolute, fixed, sticky). position: absolute; top: 0; left: 0;
z-index Σειρά στοίβαξης στον άξονα βάθους για τοποθετημένα στοιχεία. z-index: 100;
box-shadow Σκίαση πλαισίου για βάθος και σύγχρονο εφέ κάρτας. box-shadow: 0 10px 25px rgba(0,0,0,0.4);

🔍 1. F12 Developer Tools

Χρησιμοποιήστε πάντα τα εργαλεία ανάπτυξης του browser (F12 ή δεξί κλικ > Inspect) για να ελέγξετε το Box Model, να αλλάξετε CSS ζωντανά και να δείτε τυχόν σφάλματα στην κονσόλα.

🏷️ 2. Σημασιολογικό HTML (Semantic)

Αποφύγετε να χρησιμοποιείτε παντού <div>. Προτιμήστε <header>, <nav>, <main>, <article>, <footer>. Βοηθάει στην προσβασιμότητα και βαθμολογείται υψηλότερα στα πανεπιστήμια.

📦 3. Κατανόηση του Box Model

Θυμηθείτε τον κανόνα: Συνολικό πλάτος = Content width + Padding + Border + Margin. Για ευκολία, χρησιμοποιήστε * { box-sizing: border-box; } στον καθολικό επιλογέα.

⚡ 4. Καθαρή Οργάνωση Φακέλων

Διατηρείτε πάντα τα αρχεία σας οργανωμένα: το index.html στη ρίζα, ξεχωριστό φάκελο css/ για τα στυλ, images/ για εικόνες και js/ για scripts.
