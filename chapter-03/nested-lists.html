💡 Εμφωλευμένες Λίστες (Υπολίστες)

Για να δημιουργήσετε υποκατηγορίες, τοποθετήστε μια νέα λίστα <ul> ή <ol> απευθείας μέσα σε ένα στοιχείο <li>.

💻 Πηγαίος Κώδικας Παραδείγματος 
<!DOCTYPE html>
<html lang="el">
	<head>
		<meta charset="utf-8">
		<title>Εμφωλευμένες Λίστες (Nested Lists)</title>
	</head>
	<body>
		<ul>
			<li>Μους (Mousses)</li>
			<li>Γλυκά σφολιάτας (Pastries)
				<ul>
					<li>Κρουασάν (Croissant)</li>
					<li>Μιλφέιγ (Mille-feuille)</li>
					<li>Παλμιέ (Palmier)</li>
					<li>Προφιτερόλ (Profiterole)</li>
				</ul>
			</li>
			<li>Τάρτες (Tarts)</li>
		</ul>
	</body>
</html>
